# OT-0150A — Apertura auditoría bloque Volumen de referencia

## Objetivo

Seleccionar y auditar el bloque documental `## 4. Volumen de referencia` como siguiente candidato del expediente hidrológico mínimo.

## Antecedente

Los bloques `## 1. Identificación`, `## 2. Parámetros hidrológicos base` y `## 3. Tiempo de concentración y roles Tc` ya fueron delegados, validados y estabilizados.

## Candidato auditado

`## 4. Volumen de referencia`

## Alcance

Esta OT solo audita y clasifica el bloque candidato.

No implementa helper.

No modifica `ComparadorMultiMetodo.jsx`.

No sustituye `textoExpediente`.

## Precaución técnica

El bloque puede contener magnitudes hidrológicas sensibles relacionadas con lluvia efectiva, volumen esperado, volumen Q-5, área, masa y consistencia Pe–Área–Volumen.

## Restricciones

No se modifica:

- `ComparadorMultiMetodo.jsx`;
- `textoExpediente`;
- botón de copiado;
- portapapeles;
- Q-5;
- Método Racional;
- diagnóstico Q(t);
- validadores finales;
- motor hidrológico.
