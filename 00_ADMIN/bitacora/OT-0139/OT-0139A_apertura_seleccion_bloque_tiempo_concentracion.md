# OT-0139A — Apertura selección siguiente bloque documental

## Objetivo

Seleccionar y auditar el siguiente bloque documental candidato después de la adopción parcial estable de:

- `## 1. Identificación`;
- `## 2. Parámetros hidrológicos base`.

## Candidato natural

`## 3. Tiempo de concentración y roles Tc`

## Precaución técnica

Este bloque puede contener campos hidrológicamente sensibles relacionados con:

- Tc comparador;
- Tc sugerido;
- roles Tc;
- rangos de competencia;
- advertencias técnicas;
- criterios de decisión.

## Alcance

Esta OT solo audita y clasifica el bloque candidato.

No implementa helper.

No modifica `ComparadorMultiMetodo.jsx`.

No sustituye `textoExpediente`.

## Restricciones

No se modifica:

- `ComparadorMultiMetodo.jsx`;
- `textoExpediente`;
- botón de copiado;
- portapapeles;
- Q-5;
- Método Racional;
- diagnóstico Q(t);
- validadores finales;
- motor hidrológico.
